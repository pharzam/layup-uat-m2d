# tests/

The home for the **end-to-end tests** of `tally`, the Go command that counts the
lines, words and characters of text files. This project started from the
Armature kit, which ships this directory empty; it stays empty until the first
task that builds the `tally` binary adds a test here.

Go keeps a unit or integration test beside the code it tests, in a `_test.go`
file of the same package, so those tests do **not** live here: the tests of the
counting package sit in `count/`, and the tests of the command in the root
package `main`. This directory is the default `‹test directory›` only for the
tests that build `tally` and run it as a person would, with files, flags and
standard input.

## In plain terms

> The tests that run the whole `tally` command go in this folder. The small
> tests of each Go package sit next to that package's code. The folder is empty
> now because no code exists yet. The rules for what to write and how live in
> `docs/tests/`.

## Where the conventions live

This directory holds the tests; the **conventions** for writing them live in
[`docs/tests/`](../docs/tests/):

- [`docs/tests/test-levels.md`](../docs/tests/test-levels.md) — the test levels and
  the command placeholders.
- [`docs/tests/template-unit.md`](../docs/tests/template-unit.md),
  [`template-integration.md`](../docs/tests/template-integration.md),
  [`template-e2e.md`](../docs/tests/template-e2e.md) — a pattern to copy per level.
- [`docs/tests/traceability-template.md`](../docs/tests/traceability-template.md) —
  the row that ties each test back to the requirement it proves.

The project's [discipline tests](../docs/tests/test-levels.md) — the ADR, PRD,
link, PR-link and review-record linters — are not product tests and do
**not** live here; they stay beside the conventions they enforce, under
[`docs/`](../docs/).

## What comes next for tally

> The first end-to-end test goes here with the task that builds the command.
> When it lands, the same change fills the `‹test
> directory›` placeholder in [`docs/tests/test-levels.md`](../docs/tests/test-levels.md)
> and the [hook](../.githooks/pre-commit)/[CI](../docs/ci/) steps to point at it,
> and deletes the `.gitkeep` file, which only keeps this empty directory in git.

The test data that an end-to-end test needs — a file without a final line feed,
a file with a carriage return before each line feed, a file that is not valid
UTF-8, a directory — is generated by the test in a temporary directory, never
committed as a large file.
